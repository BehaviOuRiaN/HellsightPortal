# Hellsight.eu Gaming Portal

Minimalistický herný portál s iOS-inšpirovaným dizajnom. Portál je zameraný na komunitu a poskytuje katalóg hier s možnosťou pripojenia sa na Discord server.

## 🎨 Design Features

- **Minimalistický iOS-štýl**: Čierna, biela a ružová (`#e91e63`) farby
- **Responzívny dizajn**: Optimalizovaný pre všetky zariadenia
- **Smooth animations**: Plynulé prechody a animácie
- **Modern typography**: Systémové fonty pre optimálny výkon

## 📋 Obsah

### Sekcie webu:

1. **Hero Section** - Úvodná stránka s názvom portálu a CTA tlačidlom
2. **Katalóg hier** - Zoznam hier:
   - Multi Theft Auto
   - DayZ
3. **Komunita** - Discord server widget s informáciami o komunite
4. **Navigation** - Sticky navbar s plynulým scrollovaním

## 🛠️ Technológie

- HTML5
- CSS3 (s modern features: Grid, Flexbox, Gradients)
- Vanilla JavaScript (bez external dependencies)

## 📱 Responsive Design

- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (480px - 767px)
- Extra small (< 480px)

## 🚀 Nasadenie

1. Clone repository
```bash
git clone https://github.com/BehaviOuRiaN/HellsightPortal.git
cd HellsightPortal
```

2. Otvori `index.html` v prehliadači alebo:

### Cez Python:
```bash
python -m http.server 8000
```

### Cez Node.js:
```bash
npm install -g http-server
http-server
```

3. Otvor v prehliadači: `http://localhost:8000`
